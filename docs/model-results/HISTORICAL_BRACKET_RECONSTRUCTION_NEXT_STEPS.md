## Work To Do

1. Use reconstructed brackets in historical Monte Carlo replay.
2. Compare simulated knockout paths against actual historical paths.
3. Add complete pre-tournament international match history where licensing allows it.
4. Build true pre-tournament Elo snapshots from that broader history.
5. Calibrate the Elo-to-expected-goals mapping.
6. Validate champion, runner-up, group qualification, and knockout path probabilities together.
7. Prepare model outputs for future API exposure only after limitations are clearly documented.

The project should continue to avoid public accuracy claims until the replay inputs and calibration are strong enough to support them.
