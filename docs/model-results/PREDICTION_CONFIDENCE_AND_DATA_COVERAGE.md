# Prediction Confidence and Data Coverage

## Purpose

Phase 12.3 adds a deterministic confidence and data-coverage layer to `predictMatchFromLiveElo()` so the dashboard can show when a prediction is supported by direct Live Elo coverage versus fallback or sparse inputs.

This phase does not change:

- Elo ratings
- Elo-to-xG math
- Poisson probabilities
- scoreline ordering
- Monte Carlo behavior

Confidence is explanatory metadata, not a probability that the model will be correct.

## API Fields

Auto Predict responses now include `predictionConfidence` with:

- `level`: `high | medium | low | very_low`
- `coverageType`: `full | partial | fallback | fallback_only`
- `reasons`: deterministic plain-language explanations
- `dataPoints`:
  - `homeUsesFallback`
  - `awayUsesFallback`
  - `homeMatchesPlayed`
  - `awayMatchesPlayed`
  - `historicalMatchesAvailable`
  - `latestMatchDate`
  - `currentTournamentMatchesIncluded`
  - `attackDefenseAvailable`
- `manualXgRecommended`

## Coverage Types

### Full

Used only when:

- both teams use computed Live Elo ratings
- fallback is not used
- supporting metadata exists
- the dataset is not marked partial
- meaningful direct team coverage is available
- attack/defense context is available

The current project dataset is still marked partial, so most real predictions will not reach `full`.

### Partial

Used when:

- both teams use computed Live Elo ratings
- but the dataset is partial, sparse, older, or missing optional support metadata

This is the normal classification for the current curated international dataset.

### Fallback

Used when:

- exactly one team uses the fallback seed rating

### Fallback Only

Used when:

- both teams use fallback seed ratings

## Confidence Levels

### High

Reserved for the strongest non-fallback case with supporting metadata. High does not mean certain.

### Medium

Used when:

- both teams have real ratings
- but coverage is still partial or optional context is missing

### Low

Used when:

- exactly one team uses fallback
- or one team has clearly weaker direct match coverage than the other

`manualXgRecommended` is set to `true`.

### Very Low

Used when:

- both teams use fallback
- or both teams have very limited meaningful direct match coverage

`manualXgRecommended` is set to `true`.

## Reason Generation

Reasons are deterministic and local. They are not generated by an LLM.

Current examples include:

- `Both teams use computed Live Elo ratings.`
- `The international dataset is partial and curated.`
- `Haiti uses the fallback rating of 1500.`
- `No current World Cup 2026 matches are included yet.`
- `Attack and defense ratings are unavailable.`
- `Manual xG review is recommended.`

Reason ordering is fixed so tests can assert the output cleanly.

## Fallback Behavior

Fallback teams still produce a match prediction, but the confidence layer makes the limitation explicit:

- one fallback team => `low`
- two fallback teams => `very_low`

This avoids presenting fallback-based predictions as if they were supported by the same evidence as fully rated teams.

## Manual xG Recommendation

`manualXgRecommended` is a workflow hint, not an automatic override. It appears only for low-confidence and very-low-confidence auto predictions.

Manual xG mode itself does not return model confidence metadata in this phase.

## Current Limitations

- The current international dataset is still partial and curated.
- No World Cup 2026 tournament results are ingested into the Live Elo pipeline yet.
- Attack/defense context is not included in the current auto-predict request path.
- Confidence is rule-based metadata, not empirical calibration.
- Confidence does not estimate betting edge, certainty, or public accuracy.

## Future Work

Later phases can improve confidence quality by adding:

- provider freshness and sync metadata
- World Cup 2026 result ingestion
- immutable prediction snapshots
- model-vs-reality evaluation
- fallback-vs-full-coverage scoring comparisons
- better evidence for when `high` confidence is justified
