# Backtesting Assumptions

Phase 4.0G adds a historical backtesting and calibration foundation. Phase 4.0H expands the data package with complete fixture-level results for the 2010, 2014, 2018, and 2022 World Cups.

This phase does not prove model accuracy. It creates the structure needed to score supplied probability snapshots against known historical outcomes.

## What Backtesting Means

Backtesting asks: "If the model had produced these probabilities before a historical tournament, how would those probabilities compare with what actually happened?"

The project evaluates probabilities, not just winners. A good backtest should eventually report whether predictions were calibrated and whether added model complexity improves Brier Score, Log Loss, and other validation metrics.

## Foundation-Only Scope

This phase is foundation-only because:

- The probability snapshots in tests are deterministic examples, not trained model outputs.
- The model does not yet have calibrated expected goals or historical pre-tournament snapshots.
- The project does not yet compare models against a baseline over real historical reports.

## Current Dataset Coverage

The current historical fixtures include complete fixture-level results for:

- 2010 FIFA World Cup.
- 2014 FIFA World Cup.
- 2018 FIFA World Cup.
- 2022 FIFA World Cup.

That is enough to support future full-tournament reporting. It is still not enough to claim model quality because model-generated historical probability snapshots do not exist yet.

## Why These Tournaments First

2010, 2014, 2018, and 2022 provide four recent completed World Cups with the same 32-team tournament size. They are practical validation periods before modeling the expanded 48-team 2026 format.

They keep the dataset reviewable while covering group stages, knockout rounds, penalty shootouts, and finals.

## No Final Accuracy Claims

Results from this phase should not be presented as final model accuracy because:

- The probability snapshots are not generated by a calibrated model yet.
- There is no complete baseline comparison.
- Calibration buckets need more tournaments and many more predictions to be meaningful.

The current output should be described as a backtesting foundation until Phase 4.0I creates real historical reports.
