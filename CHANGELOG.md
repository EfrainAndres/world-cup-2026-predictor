- Phase 12.11D Elo-to-xG V2 Candidate Production Decision — reviewed all three Phase 12.11C candidates (`steeper-0.13`, `steeper-0.15`, `steeper-0.17`) against V1 baseline using nine explicit acceptance checks: holdout Brier improves, holdout Log Loss improves, goal MAE not materially worsened, no split major regression, predicted goals plausible, outer-bucket compression evaluable (structural failure — dataset limitation), no team-specific rules, xG bounded, symmetry preserved. Decision: `promote_to_production: steeper-0.15` (`adjustmentPer100=0.15`, `maxAdjustment=0.65`). Conservative tie-breaking (threshold=0.003 Brier) prefers `steeper-0.15` over `steeper-0.17`: the additional 0.0022 Brier improvement from 0.17 falls within sampling noise at n=120 and does not justify 70% steeper slope with unverifiable outer-bucket risk. `steeper-0.13` was excluded because the 0.0025 improvement gap to `steeper-0.15` exceeds the conservative threshold. Added `evaluateCandidateProductionDecision()` typed decision runner, `verifyV1ProductionConstantsUnchangedForDecision()` guard, `AcceptanceCheck` and `EloToXgCandidateProductionDecision` types. Added 30 focused unit tests and integration artifact test writing `docs/model-results/artifacts/elo-to-xg-v2-production-decision.json`. Added `calibration:v2-decision` script. - Phase 12.11C Elo-to-xG V2 Steeper Linear Candidate Evaluation — added `v2SteepLinearXg()` isolated candidate function (same structural form as V1 but configurable slope and cap, no team-specific rules), `runV2CandidateEvaluation()` comparison runner that evaluates a deterministic set of three steeper-linear candidates (`steeper-0.13`, `steeper-0.15`, `steeper-0.17`) against the V1 holdout baseline using the same real Poisson path (maxGoals=7, normalizeMatrix=true). Delta convention: `candidateMetric − baselineMetric` (negative = improvement for Brier/LogLoss/MAE). Acceptance gate: `eligible_for_review` when holdout Brier or Log Loss improves without materially worsening any goal MAE by more than 0.05 goals; `rejected` when MAE worsens or neither outcome metric improves; `inconclusive` when holdout is empty. All three candidates passed the gate — holdout Brier improved by −0.0047 to −0.0095 and Log Loss by −0.006 to −0.013, while goal MAE improved or held flat. Added 35 focused unit tests and an integration artifact test that loads real fixture files, builds calibration records, validates all invariants (no NaN, determinism, WC2026 isolation, V1 constants unchanged), and writes `docs/model-results/artifacts/elo-to-xg-v2-steeper-linear-candidate-summary.json`.
